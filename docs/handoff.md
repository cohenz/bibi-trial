## איך עובדים (חשוב)
- **אישור פריסה:** כל פריסה לייצור דורשת אישור מפורש של המשתמש בשיחה (מנגנון הבטיחות חוסם אחרת). "בנה את זה" אינו אישור פריסה — לשאול "לפרוס?".
- **פריסה:** GraphQL `serviceInstanceDeployV2(serviceId, environmentId, commitSha)` — **SHA מלא** (`git rev-parse`), לא לנחש מלשונית Railway המחוברת בדפדפן המובנה (`fetch("https://backboard.railway.com/graphql/v2", {credentials: "include"})`). מזהים ב־`deployment-state.md`. api ראשון כשיש migration. פריסה של worker הורגת משימה רצה — `python tools/ops.py stuck` אחר כך.
- **לוגים:** `deploymentLogs(deploymentId, filter, limit)` באותו GraphQL.
- **מפתח admin ל־Claude:** יצירת מפתח חדש (`claude-ops-2`) נחסמה במנגנון הבטיחות (הסוד היה עובר בהקשר). לא לעקוף. לאבחון: מסך "עלויות שאלות" בתוסף (משתמש במפתח של התוסף). ללא מפתח — ה־API הציבורי (`/v2/search`, `/v2/ask`, `/v2/citations/{id}`) והאדמין של וורדפרס בדפדפן המובנה.
- **קריאות admin:** `tools/ops.py` (חתימה ב־HMAC). הסוד **לא** ב־repo ולא בצ'אט: `NTK_OPS_SECRET_FILE=<קובץ>` או `NTK_OPS_SECRET`. בשיחה חדשה הסוד של `claude-ops` לא זמין. **מפתח חדש:** באישור המשתמש, ליצור סוד אקראי בסביבה, ולכתוב אותו ישירות למשתנה `NTK_SERVICE_KEYS_EXTRA` של api (JSON: `{"<key_id>": {"secret": "...", "scopes": ["admin:read","admin:ingest","admin:publish"]}}`) דרך `variableCollectionUpsert` מהדפדפן, ואז לפרוס api (גם זו פריסה — צריך אישור). אסור לקרוא את `NTK_SERVICE_KEYS` הקיים.
- **פקודות שימושיות:** `python tools/ops.py status` · `stuck` · `failed` · `call GET /v2/admin/batches` · `call POST /v2/admin/guides/witness-policy '{"apply": false}'` · `call GET /v2/admin/ask/usage days=7`.
- **תצוגה ובדיקת ניגודיות של התוסף:** `tools/preview/` (README שם). השרת בענן לא מגיע לאתר עצמו — לבדוק את האתר החי בדפדפן המובנה.
- **בדיקות:** `NTK_TEST_ADMIN_URL=postgresql+psycopg://ntk:ntk@localhost:5432/postgres python -m pytest -q` (Postgres מקומי; אם הסיסמה נדחית — `ALTER ROLE ntk PASSWORD 'ntk'`). בתוסף: `php wordpress/trial-knowledge/tests/run.php`. בניית ZIP: `bash tools/build_plugin_zip.sh` → `dist/` (לא ב־git; שולחים למשתמש).
- **עלויות:** המשתמש רגיש לעלויות — כל שליחה גדולה לג'מיני רק באישור, עם ניסיון קטן קודם.
